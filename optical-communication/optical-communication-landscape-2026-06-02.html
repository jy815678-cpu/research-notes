第一部分：光如何在光纤中奔跑？

1.1 全反射：光的”镜面隧道”

光纤的核心原理是全反射（Total Internal Reflection）——这是光在两种介质界面上发生的一种奇妙现象。

斯涅尔定律（Snell’s Law）：

$$n_1 \sin\theta_1 = n_2 \sin\theta_2$$

其中 $n_1$ 和 $n_2$ 是两种介质的折射率，$\theta_1$ 和 $\theta_2$ 是入射角和折射角。

关键条件：当光从高折射率介质射向低折射率介质时，如果入射角大于临界角 $\theta_c$，光就不会折射出去，而是全部反射回来：

$$\theta_c = \arcsin\left(\frac{n_2}{n_1}\right)$$ 
    全反射示意图：

    高折射率 n₁（玻璃芯）
    │
    │   ╲
    │    ╲  θ₁ > θc
    │─────╳─────  ← 界面
    │      ╲
    │       ╲  （全反射，无折射光）
    │
    低折射率 n₂（包层）

    光纤结构：
    ┌─────────────────┐
    │   纤芯 (Core)   │  ← 高折射率玻璃，n₁≈1.47
    │   (~8-50 μm)    │     光在这里传输
    ├─────────────────┤
    │  包层 (Cladding)│  ← 低折射率玻璃，n₂≈1.45
    │  (~125 μm)      │
    ├─────────────────┤
    │  涂覆层 (Coating│  ← 塑料保护层
    │   ~250 μm)      │
    └─────────────────┘

光纤的尺度：
- 纤芯直径：$8\sim50\,\mu\text{m}$（比头发丝还细！）
- 包层直径：$125\,\mu\text{m}$（标准尺寸）
- 涂覆后直径：$250\,\mu\text{m}$（约3根头发丝粗）

类比：光纤像一条极细的镜面隧道。光在隧道里不断”弹跳”前进，永远不会撞破墙壁——因为墙壁（包层）的折射率比隧道内部（纤芯）低，光在界面上被”弹”了回来。

1.2 两种光纤：单模 vs 多模

根据纤芯粗细，光纤分为两类：

    多模光纤 (MMF)              单模光纤 (SMF)

    ┌─────────────┐            ┌───┐
    │             │            │   │
    │   大纤芯    │            │细芯│
    │   50 μm     │            │8μm│
    │             │            │   │
    └─────────────┘            └───┘

    多束光模式同时传输          只有一束光（基模）
    模式色散严重                几乎无色散
    短距离、低成本              长距离、高成本
    LED光源即可                 需要激光器

为什么单模光纤更好？

多模光纤中，不同”模式”的光走的路径不同——有的走直线，有的走”之”字形。它们到达时间不同，导致信号”模糊”。这叫做模态色散。

单模光纤的纤芯极细，只允许一种模式传播，从根本上消除了模态色散。

类比：多模光纤像一条宽马路，行人可以并排走、斜着走、绕来绕去地走——大家到达时间参差不齐。单模光纤像一条极窄的独木桥——只能排队走，所以 everyone’s arrival time is synchronized。

1.3 光在光纤中真的在”跑”吗？

光在光纤中的传播速度不是真空光速 $c$，而是：

$$v = \frac{c}{n} \approx \frac{3 \times 10^8}{1.5} = 2 \times 10^8 \, \text{m/s}$$

也就是说，光在玻璃中慢了约1/3。

但这还不是全部——由于全反射，光走的是”之”字形路径，实际路径比直线长。有效传播速度约为：

$$v_{eff} = \frac{c}{n_{eff}} \approx \frac{c}{1.47} \approx 2.04 \times 10^8 \, \text{m/s}$$

一个数字：从北京到上海约$1200\,\text{km}$，光在光纤中需要约6毫秒。这大概就是光在玻璃中”奔跑”的速度。

第二部分：色散与损耗——光的”疲劳”

2.1 损耗：光跑远了会变弱

即使光纤是极高纯度的玻璃，光在传播中还是会逐渐变弱。这是因为：

吸收损耗：
- 紫外吸收：玻璃中的电子跃迁吸收紫外光
- 红外吸收：Si-O键的分子振动吸收红外光
- 杂质吸收：OH⁻（水分子）在$1380\,\text{nm}$处有强吸收峰

散射损耗：
- 瑞利散射：玻璃分子密度的微观不均匀性散射光。瑞利散射强度与波长的四次方成反比：

$$\alpha_{Rayleigh} \propto \frac{1}{\lambda^4}$$

这就是为什么：
- 天空是蓝色的（蓝光波长短，散射强）
- sunsets是红色的（红光波长长，散射弱，穿透力强）
- 光纤通信偏好$1550\,\text{nm}$（损耗最小）

    光纤损耗谱：

    损耗 (dB/km)
    0.5 │        ╭────╮
        │       ╱      ╲
    0.3 │      ╱   ③   ╲     ③ = 1550 nm (C-band)
        │  ①  ╱          ╲    损耗 ~0.2 dB/km
    0.2 │──╮─╱            ╲──
        │  ╲╱              ②
        │  ②               ② = 1310 nm
    0.1 │                    损耗 ~0.35 dB/km
        │
        └────────────────────→ 波长 (nm)
           800  1100  1310  1550  1800

现代光纤的损耗：在$1550\,\text{nm}$窗口，优质光纤的损耗低至$0.17\,\text{dB/km}$。

这意味着光跑$100\,\text{km}$后，功率只衰减到原来的约4%。

类比：光纤损耗像声音在空气中传播。你喊话，远处的人听到的声音越来越小——空气分子散射和吸收了一部分声能。光纤中的玻璃分子对光做同样的事情。

2.2 色散：不同颜色的光跑速不同

即使你只发射一种颜色的光，光脉冲还是会在传播中”变宽”。这是因为色散——不同频率（颜色）的光在光纤中传播速度不同。

色散的类型：

类型 原因 影响
模态色散 不同模式走不同路径 仅多模光纤
材料色散 玻璃折射率随波长变化 所有光纤
波导色散 光场分布随波长变化 所有光纤

材料色散：

玻璃的折射率 $n$ 不是常数，而是随波长变化：

$$n(\lambda) = n_0 - \frac{\lambda^2}{2} \frac{d^2n}{d\lambda^2}$$

这意味着：
- 蓝光（短波长）跑得慢
- 红光（长波长）跑得快

    色散导致脉冲展宽：

    发射端：                接收端（100 km后）：

    强度                    强度
    │  ╭╮                   │  ╭────╮
    │  ││                   │ ╱      ╲
    │  ││                   │╱        ╲
    └──┴┴──→ t              └──────────→ t
       ↑                      ↑    ↑
    窄脉冲                  脉冲变宽
                            "0"和"1"重叠
                            → 误码！

色散补偿：

  1. 色散补偿光纤（DCF）：一段特殊设计的光纤，具有负色散，抵消普通光纤的正色散
  2. 啁啾光纤光栅（FBG）：用光栅引入波长相关的延迟
  3. 数字信号处理（DSP）：在接收端用算法”反折”色散效应

类比：色散像一群不同速度的人在跑马拉松。发令枪响时大家站成一排（一个窄脉冲），但跑得快的（红光）逐渐领先，跑得慢的（蓝光）落后——到达终点时，队伍已经拉得很长（脉冲展宽）。如果队伍拉得太长，你分不清谁是谁了（误码）。

2.3 非线性效应：强光下的”脾气”

当光功率足够高时，光纤会表现出非线性行为：

自相位调制（SPM）：光自身的强度改变了它自己的相位

$$\Delta\phi = \frac{2\pi n_2 I L}{\lambda}$$

其中 $n_2$ 是非线性折射率，$I$ 是光强，$L$ 是传播距离。

受激布里渊散射（SBS）和受激拉曼散射（SRS）：光把能量转移给玻璃分子，产生新的频率成分。

四波混频（FWM）：不同波长的光相互作用，产生新的波长。

这些非线性效应在WDM系统（多波长同时传输）中尤其麻烦，会限制系统的传输容量。

第三部分：如何把信息”写”到光上？

3.1 调制：让光”记住”比特

光本身只是电磁波。要让它携带信息，需要调制（Modulation）——改变光的某个属性来表示0和1。

可调的属性：

属性 调制方式 简单性 抗噪声
振幅 ASK / OOK ⭐⭐⭐ ⭐⭐
频率 FSK ⭐⭐ ⭐⭐⭐
相位 PSK / QPSK ⭐⭐ ⭐⭐⭐⭐
偏振 PolSK ⭐ ⭐⭐⭐

OOK（On-Off Keying，开关键控）

最简单的调制：有光=1，无光=0。

    OOK调制：

    比特流：  1   0   1   1   0   1   0   0
             │   │   │   │   │   │   │   │
    光功率：  ▄   ▁   ▄   ▄   ▁   ▄   ▁   ▁
             ↑   ↑   ↑   ↑   ↑   ↑   ↑   ↑
            亮  暗  亮  亮  暗  亮  暗  暗

    就像用手电筒的闪烁传递摩斯电码

OOK简单，但频谱效率低——每符号只传1比特。

PAM4（Pulse Amplitude Modulation 4-level）

用4个振幅级别表示2比特：

    PAM4调制：

    振幅：
    3 ────  ← 11
    2 ────  ← 10
    1 ────  ← 01
    0 ────  ← 00

    比特：00  10  11  01  00  10

    频谱效率翻倍！但抗噪声能力下降
    （4个级别挤在同样的振幅空间里）

PAM4是当前400G/800G光模块的主流调制格式。

QPSK（Quadrature Phase Shift Keying）

用4个相位表示2比特：

    QPSK星座图：

    虚部 (Quadrature)
         │
    01 ● │ ● 11
    ─────┼─────→ 实部 (In-phase)
    00 ● │ ● 10
         │

    4个相位：45°, 135°, 225°, 315°
    每符号传2比特

QPSK的频谱效率比OOK高一倍，而且所有符号的能量相同（恒包络），抗非线性更强。

QAM（Quadrature Amplitude Modulation）

同时调制振幅和相位：

    16-QAM星座图：

         │ ● ● ● ●
         │ ● ● ● ●
         │ ● ● ● ●
         │ ● ● ● ●
         └────────→

    16个符号，每符号传4比特
    频谱效率是OOK的4倍！
    但需要很高的信噪比（SNR）

相干检测（Coherent Detection）：

要解调QPSK和QAM，需要相干检测——在接收端用一束本振激光与信号光混频，同时恢复振幅和相位信息。

    相干接收机：

    信号光 ──→ ┌─────┐
               │  90° │  ← 光混频器
    本振光 ──→ │ 耦合 │     (Optical Hybrid)
               └──┬──┘
                  │
           ┌──────┼──────┐
           ▼      ▼      ▼
        I路      Q路    相位
       (实部)   (虚部)  信息

相干检测可以把光的全部信息（振幅、相位、偏振）都提取出来，是长距离高速光通信的核心技术。

类比：调制像写信。OOK像摩斯电码——只有点和划。PAM4像四级数字密码。QPSK像用方向写字：北=00，东=01，南=10，西=11。QAM像同时用方向和笔的粗细来编码——信息密度最高，但也最容易写错（需要高信噪比）。

3.2 复用：一根光纤传多路信号

一根光纤的带宽潜力巨大。如何充分利用？答案是复用。

WDM（Wavelength Division Multiplexing，波分复用）

    WDM原理：

    不同波长的光，在同一根光纤中独立传输

    功率
     │  ╭╮  ╭╮  ╭╮  ╭╮  ╭╮  ╭╮  ╭╮  ╭╮
     │  ││  ││  ││  ││  ││  ││  ││  ││
     └──┴┴──┴┴──┴┴──┴┴──┴┴──┴┴──┴┴──┴┴──→ λ
        λ₁  λ₂  λ₃  λ₄  λ₅  λ₆  λ₇  λ₈

    发送端：合波器（MUX）把多路光合并
    光纤中：各路光互不干扰
    接收端：分波器（DEMUX）把各路光分开

WDM的级别：

类型 波长间隔 通道数 总容量
CWDM（粗波分） 20 nm ~8 低
DWDM（密集波分） 0.8 nm (100 GHz) ~80 高
UDWDM（超密集） 0.1 nm ~1000 极高

现代海底光缆使用DWDM，单根光纤可传输数十Tbps。

TDM（Time Division Multiplexing，时分复用）

把时间切成小片，不同用户轮流使用光纤：

    TDM：

    时间轴 →

    用户A：█░░░█░░░█░░░█░░░
    用户B：░█░░░█░░░█░░░█░░
    用户C：░░█░░░█░░░█░░░█░

    每用户占用一个时隙

TDM在电域更常见，光域主要用WDM。

第四部分：光通信的”器官”——关键器件

4.1 激光器：光的”心脏”

光通信需要单色性好、方向性好、功率稳定的光源——这就是激光器。

DFB激光器（Distributed Feedback Laser）

    DFB激光器结构：

    ┌────────────────────────────────┐
    │  ●━━━━━━━●━━━━━━━●━━━━━━━●   │  ← 光栅（布拉格光栅）
    │  ↑       ↑       ↑       ↑   │     周期 Λ = λ/2n
    │  有源区（InGaAsP）            │
    │        ↓ 电注入               │
    └────────────────────────────────┘

    光栅提供反馈，选择特定波长
    线宽 < 0.1 nm

DFB激光器通过布拉格光栅选择特定波长，线宽极窄（<0.1 nm），是DWDM系统的标准光源。

VCSEL（Vertical-Cavity Surface-Emitting Laser）

    VCSEL结构（垂直方向发射）：

    ┌─────────┐  ← 上布拉格反射镜
    │         │
    │ 有源区  │  ← 薄量子阱（几nm）
    │         │
    ├─────────┤  ← 下布拉格反射镜
    │   衬底  │
    └─────────┘
         │
         ▼
      光垂直向下发射

    优点：低成本、低功耗、易阵列化
    应用：数据中心短距互连（几十米）

VCSEL是数据中心的”主力军”——便宜、可靠、可以做成阵列。

4.2 调制器：让光”说话”的器官

直接调制激光器（改变注入电流）会产生啁啾（Chirp）——频率漂移，导致色散问题。高速系统使用外部调制器。

MZM（Mach-Zehnder Modulator）

    MZM结构：

    光输入
       │
       ▼
    ┌──┴──┐
    │ 分束 │  →  ────┬────  上臂（施加电压V）
    └──┬──┘         │
       │            │  相位差 Δφ = πV/Vπ
       │            │
       │           ─┴─   下臂（参考）
       │            │
       │            │
    ┌──┴──┐       ──┴──
    │ 合束 │  ← 干涉输出
    └──┬──┘
       │
       ▼
    光输出

    输出强度：I = I₀ cos²(Δφ/2)

MZM就是你在实验室里熟悉的Mach-Zehnder干涉仪——只不过两臂上加了电极，用电场改变折射率，从而改变相位差。

铌酸锂（LiNbO₃）MZM：带宽可达$100\,\text{GHz}$以上，是长距离相干通信的核心器件。

硅光MZM：在硅芯片上集成，成本低，但性能略逊，适合数据中心。

4.3 探测器：光的”耳朵”

PIN光电二极管

    PIN结构：

    ┌─────┬─────┬─────┐
    │  P  │  I  │  N  │
    │重掺杂│本征 │重掺杂│
    │     │(耗尽层)│   │
    └─────┴─────┴─────┘
         ↑
      光子在这里被吸收
      产生电子-空穴对
      形成光电流

响应度：

$$R = \frac{\eta q}{h\nu} \approx \frac{\eta \lambda}{1.24} \, (\text{A/W})$$

其中 $\eta$ 是量子效率。在$1550\,\text{nm}$，硅探测器不工作（带隙太大），需要用InGaAs（铟镓砷）。

APD（雪崩光电二极管）

在PIN基础上增加雪崩倍增区，增益$M = 10\sim100$。

InGaAs APD是$1550\,\text{nm}$接收机的标准选择。

4.4 光放大器：给光”加油”

光在光纤中传输会衰减。如果不用放大器，每$100\,\text{km}$信号就会太弱而无法检测。

EDFA（Erbium-Doped Fiber Amplifier，掺铒光纤放大器）

    EDFA结构：

    输入光 ──→ ┌──────────┐ ──→ 输出光
               │  掺铒光纤 │     （信号被放大）
               │  (~10m)  │
               └─────┬────┘
                     │
              泵浦激光 (980nm)
                     │
                     ▼
               能量转移：
               泵浦光 → 铒离子激发 → 信号光受激辐射

EDFA的魔法：
- 直接放大光信号，无需光电转换
- 增益高达$30\,\text{dB}$（1000倍功率放大）
- 带宽极宽（$30\,\text{nm}$，覆盖整个C-band）
- 噪声系数低（$\sim4\,\text{dB}$）

EDFA是光通信革命的关键发明——它让跨洋光缆不需要电子中继器，大大提升了可靠性和容量。

类比：EDFA像高速公路上的加油站。汽车（光信号）跑远了油（能量）不够了，直接加油继续跑——不需要把油取出来、精炼、再灌回去（光电转换）。

5.2 海底光缆：人类最伟大的工程之一

全球有超过500条海底光缆，总长度超过130万公里，承载了99%的国际数据流量。

    海底光缆结构：

    直径 ~20-30 mm（比大拇指粗一点）

    ┌──────────────────────────────────────┐
    │  聚乙烯护套                          │
    ├──────────────────────────────────────┤
    │  钢丝铠装（防鲨鱼咬！）               │
    ├──────────────────────────────────────┤
    │  铝制防水护套                        │
    ├──────────────────────────────────────┤
    │  铜导线（供电给中继器）               │
    ├──────────────────────────────────────┤
    │  光纤束（~4-8对光纤）                │
    │  每对：一根传、一根收                │
    │  每根光纤：多芯（多芯光纤）          │
    └──────────────────────────────────────┘

跨洋传输系统：

一条典型的跨大西洋光缆（如Marea）：
- 长度：$6600\,\text{km}$
- 光纤对数：8对
- 每对光纤容量：$200\,\text{Tbps}$
- 总容量：$1600\,\text{Tbps}$
- 中继器间距：$\sim50\,\text{km}$
- 中继器数量：$\sim130$个

中继器（Repeater）：

海底光缆每$50\,\text{km}$左右需要一个中继器。现代中继器包含：
- EDFA光放大器（双向）
- 遥测和监控电路
- 供电电路（从岸站通过铜导线供电，电压可达$10\,\text{kV}$）

    ├────────────┤                    ├────────────┤
    │  多层护套   │                    │  轻铠装     │

5.3 数据中心光互连

数据中心是光通信增长最快的领域。为什么？

电信号的瓶颈：

当数据速率超过$25\,\text{Gbps}$时，铜线的问题越来越严重：
- 损耗大：铜线在$10\,\text{GHz}$以上衰减严重
- 串扰：相邻铜线之间的电磁干扰
- 功耗：驱动铜线需要大量能量

光互连的优势：
- 低损耗（光纤衰减$\sim0.2\,\text{dB/km}$，铜线在$10\,\text{GHz}$时$\sim100\,\text{dB/km}$）
- 无串扰（光不互相干扰）
- 低功耗（光信号传输几乎不耗能）

    数据中心内部光互连层级：

    机架顶交换机 (ToR)
         │
    ┌────┴────┐
    │ AOC光缆 │  ← 有源光缆（Active Optical Cable）
    │ ~1-5m  │     光电转换集成在接头里
    └────┬────┘
         │
    服务器网卡
         │
    ┌────┴────┐
    │ 光模块  │  ← QSFP-DD / OSFP，400G/800G
    │ (可插拔)│
    └────┬────┘
         │
    核心交换机
         │
    ┌────┴────┐
    │ 光纤    │  ← MPO/MTP多芯光纤
    │ ~10-100m│
    └────┬────┘
         │
    其他核心交换机

AOC（Active Optical Cable）

把光纤和光收发器集成在一起，像一根”粗一点的网线”：

    AOC结构：

    ┌─────┐══════════════════════┌─────┐
    │电接头│  光纤 + 光收发器集成  │电接头│
    │(QSFP)│  在接头内部          │(QSFP)│
    └─────┘══════════════════════└─────┘

    长度：1-100米
    速率：100G/400G/800G
    优点：即插即用，无需单独配光模块

CPO（Co-Packaged Optics，光电共封装）

下一代技术：把光引擎和交换机芯片封装在一起：

    传统方案：                     CPO方案：

    ┌─────────────┐              ┌─────────────────┐
    │  交换机芯片  │              │  ┌───────────┐  │
    │  (电信号)   │              │  │交换机芯片 │  │
    └──────┬──────┘              │  │(电接口)   │  │
           │                     │  └─────┬─────┘  │
    ┌──────┴──────┐              │        │ 极短走线│
    │  电走线     │              │  ┌─────┴─────┐  │
    │  (~10cm)    │              │  │ 光引擎    │  │
    └──────┬──────┘              │  │(MZM/探测器)│ │
           │                     │  └─────┬─────┘  │
    ┌──────┴──────┐              │        │        │
    │  光模块     │              │    光纤输出     │
    │(E-O转换)    │              └─────────────────┘
    └──────┬──────┘
           │
        光纤输出

    CPO优势：
    - 电走线极短（毫米级），功耗大幅下降
    - 速率可扩展到3.2Tbps+

CPO预计将在2025-2027年进入大规模商用。

第六部分：硅光子学——在芯片上造光路

6.1 为什么要硅光？

电子芯片的速度越来越快，但电信号在长距离传输中遇到了瓶颈：

问题 原因 后果
RC延迟 导线电阻+寄生电容 信号边沿变缓
功耗 驱动长导线需要能量 数据中心40%能耗在互连
串扰 电磁耦合 信号完整性下降
带宽密度 铜线占面积大 I/O引脚成为瓶颈

光的解决方案：
- 光信号在波导中传输几乎无损耗
- 不同波长的光互不干扰（WDM）
- 光波导可以做得极细（亚微米级）
- 带宽密度比铜线高$100\times$以上

6.2 硅光波导

硅的折射率（$n\approx3.5$）远高于二氧化硅（$n\approx1.5$），所以可以在硅芯片上制作高折射率对比度的波导：

    硅光波导截面：

    ┌─────────────────────┐
    │   SiO₂ 包层 (n=1.5)  │
    │  ┌───────────────┐  │
    │  │  Si 芯层      │  │  ← 高折射率 (n=3.5)
    │  │  (220×500 nm) │  │     光被约束在内部
    │  └───────────────┘  │
    │   SiO₂ 包层 (n=1.5)  │
    └─────────────────────┘
         Si 衬底

    约束机制：全反射（与光纤类似）
    但折射率对比度更高 → 波导可以极细

SOI（Silicon-on-Insulator）平台：

在硅衬底上生长一层薄的$\text{SiO}_2$（ buried oxide，BOX），再在上面沉积一层薄硅（$\sim220\,\text{nm}$）。这层薄硅就是光波导的”舞台”。

6.3 硅光器件全家福

    硅光芯片上的器件：

    激光输入 ──→ ┌─────────────────────────────┐
                 │                             │
                 │  ┌───┐  ┌───┐  ┌───┐       │
                 │  │MZI│  │MZI│  │MZI│ ...   │  ← 调制器阵列
                 │  └───┘  └───┘  └───┘       │
                 │     │      │      │         │
                 │  ┌──┴──┬───┴──┬───┴──┐     │
                 │  │     │      │      │     │
                 │  ▼     ▼      ▼      ▼     │
                 │  ┌─────────────────────┐   │
                 │  │    波分复用器        │   │  ← AWG / Echelle
                 │  │   (MUX/DEMUX)       │   │
                 │  └──────────┬──────────┘   │
                 │             │              │
                 │             ▼              │
                 │         光纤输出           │
                 │                             │
                 └─────────────────────────────┘

定向耦合器（Directional Coupler）

    定向耦合器：

    输入1 ──→ ────────┬──────── ──→ 输出1
                      │  消逝场耦合
    输入2 ──→ ────────┴──────── ──→ 输出2

    两根波导靠得足够近 → 光"跳"到另一根
    耦合比例由平行长度和间距决定

定向耦合器是硅光芯片的”基础乐高积木”——MZI、耦合器、分束器都靠它实现。

MZI调制器（Silicon Photonics MZM）

在硅波导两侧加电极，利用等离子体色散效应（自由载流子改变折射率）调制相位：

$$\Delta n = -\frac{e^2 \lambda^2}{8\pi^2 c^2 \varepsilon_0 n}\left(\frac{\Delta N_e}{m_e^*} + \frac{\Delta N_h^{0.8}}{m_h^*}\right)$$

通过改变载流子浓度（注入电流），改变折射率，从而改变相位——这就是硅光MZM的物理原理。

问题：载流子寿命限制了调制速度（$\sim1\,\text{GHz}$）。高速应用需要预加重或推挽结构。

微环谐振器（Microring Resonator）

    微环谐振器：

    直波导 ──→ ────────●──────── ──→
                        │
                        ↓
                      ╭───╮
                     │  ◯  │  ← 微环（半径几微米）
                      ╰───╯
                        ↑
    当环周长 = m·λ时，发生谐振
    光被"困"在环里，直波导输出被抑制

    应用：
    - 滤波器（选择特定波长）
    - 调制器（改变谐振波长）
    - 传感器（环境变化改变谐振）

微环是硅光芯片上最紧凑的器件之一——一个环形波导只有几微米大小。

6.4 硅光的挑战

挑战 原因 解决方案
硅不发光 间接带隙 外部激光器（InP）键合到硅上
调制速度受限 载流子寿命 推挽结构、预加重、GeSi电吸收调制器
耦合损耗 光纤模式 vs 硅波导模式不匹配 光栅耦合器、边缘耦合器
温度敏感 硅折射率温度系数高 温控、设计容差

6.5 硅光的未来：光I/O

未来的CPU/GPU可能直接用光来”说话”：

    未来芯片架构：

    ┌─────────────────────────────────────┐
    │  ┌─────┐  光I/O  ┌─────┐  光I/O  ┌─────┐ │
    │  │CPU  │←──────→│HBM  │←──────→│GPU  │ │
    │  │芯片 │  光纤   │存储 │  光纤   │芯片 │ │
    │  └─────┘         └─────┘         └─────┘ │
    │       \          │          /       │
    │        \         │         /        │
    │         \        │        /         │
    │          \       │       /          │
    │           \      │      /           │
    │            \     │     /            │
    │         ┌───────┴────┴───────┐      │
    │         │    光互连交换机     │      │
    │         │   (Optical Switch) │      │
    │         └───────────────────┘      │
    └─────────────────────────────────────┘

    优势：
    - 芯片间带宽：数Tbps
    - 延迟：亚微秒
    - 功耗：比电互连低10倍

写在最后

光通信是人类工程史上最成功的技术之一。它让信息以光速在全球范围内流动，把世界连接成一个整体。

从1966年高锟提出光纤通信的理论基础，到今天海底光缆承载99%的国际流量——这是短短60年的奇迹。

当你下次刷手机、看视频、打视频电话时，请记住：你指尖的信息，正以光的速度，在比头发丝还细的光纤中奔跑，穿过山脉、海洋、城市，最终到达另一块屏幕。

而未来，光不仅会连接城市，还会连接芯片。硅光子学正在把光路”缩小”到芯片尺度，让光成为计算机内部的”神经纤维”。

一个数字：2024年，全球光纤通信系统的总传输容量已超过1 Zettabyte（$10^{21}$字节）/年。这相当于每秒传输$3\times10^{13}$比特——如果把每个比特比作一粒沙子，每秒传输的沙子可以填满一个标准游泳池。

这就是光的魔力——它不仅是宇宙的速度极限，也是人类信息文明的动脉。
