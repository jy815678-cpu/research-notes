文档导读

你可能在新闻里看到过：自动驾驶汽车头顶着一个”大花盆”，不停地旋转，那就是激光雷达。但激光雷达远不止于此——从无人机测绘到iPhone的Face ID，从气象观测到火星探测，激光雷达正在渗透进我们生活的每个角落。

  • 为什么有的激光雷达转得像雷达，有的却一动不动？
  • 1550nm和905nm的激光，差的不只是数字，还有安全性？
  • 激光雷达看到的”点云”，和相机拍的照片，到底有什么区别？

读完之后，你应该能够自信地参与任何关于激光雷达的对话，甚至判断某个激光雷达方案的技术含金量。

第一部分：激光测距的物理本质

1.1 光速是宇宙的速度极限

激光雷达测距的核心原理，比你想象的还要简单——它利用了光速的有限性。

光在真空中的速度是：

$$c = 299,792,458 \, \text{m/s} \approx 3 \times 10^8 \, \text{m/s}$$

这个速度极快，但并非无限快。一束光从地球到月球只需要约1.3秒，但在激光雷达的尺度上——比如测量30米外的障碍物——光往返只需要：

$$\Delta t = \frac{2d}{c} = \frac{2 \times 30}{3 \times 10^8} = 200 \, \text{ns}$$

200纳秒！这是人眼根本无法感知的短暂时间。但现代电子设备可以轻松测量它。

类比：想象你在一个巨大的峡谷里喊话。声音传播的速度约340 m/s，如果你听到回声花了2秒，你知道峡谷对面在340米外。激光雷达做的事情一模一样——只不过它用的是光，而不是声音。

1.2 ToF：测量光的”往返时间”

ToF（Time of Flight，飞行时间）是最直接的测距方法：

    激光雷达          障碍物          激光雷达
       │                │                │
       │  ──────────→   │                │
       │   t = 0        │                │
       │                │                │
       │  ←──────────   │                │
       │   t = Δt       │                │
       │                │                │

    距离 d = c × Δt / 2

激光雷达发射一个极短的光脉冲（通常只有几纳秒宽），同时启动一个高精度的计时器。当反射光返回到探测器时，计时器停止。时间差 $\Delta t$ 的一半乘以光速，就是目标的距离。

ToF的关键挑战：

挑战 原因 解决方案
时间测量精度 1 ns 误差 = 15 cm 距离误差 使用SPAD（单光子雪崩二极管）+TDC（时间数字转换器）
微弱回波信号 目标可能只反射很少的光 高灵敏度探测器、多脉冲累积
多目标重叠 一个激光束照射到多个物体 波形分析、多回波检测
环境光干扰 阳光也可能触发探测器 窄带滤光片、时间门控

一个数字：高端ToF激光雷达的时间测量精度可达10皮秒（ps），对应1.5毫米的距离精度。这意味着它可以分辨出两个相距仅1.5毫米的物体。

1.3 FMCW：用频率”编码”距离

ToF直接测量时间，但还有另一种更优雅的方法——FMCW（Frequency Modulated Continuous Wave，调频连续波）。

FMCW的核心思想：不是发射脉冲，而是发射一束频率在不断变化的连续激光。

    FMCW 原理：

    发射光频率
       │    ╱╲    ╱╲    ╱╲
       │   ╱  ╲  ╱  ╲  ╱  ╲
       │  ╱    ╲╱    ╲╱    ╲
       └────────────────────→ 时间
            ↑
         线性调频（Chirp）
         频率从 f₀ 扫到 f₀+Δf

    回波信号：同样的频率变化，但延迟了 Δt

    发射与回波"混频" → 产生拍频（Beat Frequency）

    f_beat ∝ Δt ∝ 距离

想象一下：你吹着口哨，音调越来越高。你的口哨声遇到墙壁反射回来。因为你一直在提高音调，反射回来的声音总是比你现在吹的音调低——这个音调差，正比于声音往返的时间，也就是正比于距离。

数学上：

如果发射光的频率线性变化：

$$f_{TX}(t) = f_0 + \frac{B}{T} \cdot t$$

其中 $B$ 是频率扫描范围，$T$ 是扫描时间。回波信号延迟了 $\Delta t = 2d/c$，其频率为：

$$f_{RX}(t) = f_0 + \frac{B}{T} \cdot (t - \Delta t)$$

两者混频后产生的拍频：

$$f_{beat} = f_{TX} - f_{RX} = \frac{B}{T} \cdot \Delta t = \frac{2Bd}{cT}$$

FMCW的魔法：
- 直接测量频率（容易且精确），而不是时间（困难）
- 同时获得距离和速度（通过多普勒频移）
- 抗干扰能力极强（只有相干光才能产生拍频）

类比：ToF像拍球——你拍出去，等它弹回来。FMCW像两个音叉——你发出一个持续变化的声音，听回声和你当前声音的”音差”来判断距离。

1.4 ToF vs FMCW：两种哲学的对比

特性 ToF（脉冲式） FMCW（连续波）
测距原理 直接测时间 间接测拍频
光源 脉冲激光器 窄线宽可调激光器
探测器 SPAD、APD 平衡光电探测器
同时测速 ❌ 不能 ✅ 能（多普勒）
抗阳光干扰 中等 极强（相干检测）
技术成熟度 高（量产） 中（正在量产）
代表厂商 Velodyne、禾赛、速腾 Aurora、SiLC、Mobileye

第二部分：扫描——让激光”看”遍四面八方

2.1 为什么需要扫描？

一束激光只能照亮一个点。要”看到”周围的世界，你需要让这束光扫过整个视野——就像你用手电筒在黑暗中扫视房间一样。

扫描的本质：在二维或三维空间中，有规律地改变激光束的指向。

2.2 机械旋转式：最经典的”大花盆”

    机械旋转式LiDAR侧视图：

         ↑
        ╱ ╲
       ╱   ╲     ← 旋转的激光发射/接收模块
      ╱  ●  ╲        （像旋转木马一样转）
     ╱       ╲
    └─────────┘
         │
    ┌─────────┐
    │  电机   │  ← 驱动旋转，通常 5-20 Hz
    └─────────┘
         │
    ┌─────────┐
    │  基座   │  ← 固定在车顶
    └─────────┘

机械式激光雷达把激光发射器和探测器装在一个旋转的平台上，通常以5-20转/秒的速度旋转。每转一圈，它发射数千束激光，覆盖360°水平视野。

优点：
- 视野覆盖完整（360°水平）
- 技术成熟，性能稳定
- 探测距离远（200m以上）

缺点：
- 机械部件多，可靠性差（振动、磨损）
- 体积大、成本高（早期Velodyne HDL-64E售价$75,000）
- 旋转部件寿命有限

类比：机械旋转式LiDAR像一个旋转的灯塔。灯塔的光束扫过海面，每隔几秒就照亮同一个点一次。激光雷达也一样，只不过它每秒转得更快，光束更细。

2.3 MEMS：用芯片上的”小镜子”扫描

MEMS（Micro-Electro-Mechanical Systems，微机电系统）激光雷达用一块极小的硅镜来代替整个旋转机构。

    MEMS 微镜扫描：

    激光器 ──→ ╲     ╱  ← MEMS微镜（1-5mm大小）
                ╲   ╱      绕两个轴快速振动
                 ╲ ╱
                  ▼
               扫描图案
              （光栅式）

    微镜结构（截面）：

    ┌─────────┐
    │  硅镜   │  ← 镜面镀有高反射率金属
    ├─╂─────╂─┤  ← 扭转梁（像弹簧铰链）
    │ │     │ │
    └─┴─────┴─┘  ← 硅基底

这块镜子只有几毫米大小，通过静电或电磁力驱动，以kHz级频率在两个轴上快速振动。激光照射到镜子上，被反射到不同方向，形成扫描图案。

优点：
- 体积小（可以藏进汽车保险杠）
- 成本低（可批量生产）
- 可靠性高（无机械旋转部件）

缺点：
- 视野较窄（通常120°水平 × 25°垂直）
- 振动角度有限（通常±15°）
- 探测距离相对较短

代表厂商：Luminar、Innoviz、Velodyne Velabit

类比：MEMS LiDAR像一只快速转动的眼球。你的眼睛不需要转整个头来扫视——只需要转动眼球就能覆盖大部分视野。MEMS微镜就是LiDAR的”眼球”。

2.4 OPA：相控阵——没有活动部件的”魔法”

OPA（Optical Phased Array，光学相控阵）是激光雷达的”终极形态”之一。它没有机械运动部件，也没有振动微镜——它用波的干涉来控制光的方向。

核心原理：

想象一排人站在泳池边，同时跳入水中。如果所有人都同时跳，波纹会向四面八方传播。但如果让左边的人先跳，右边的人后跳——波纹就会偏向右边传播。

OPA就是这样做的一排光发射器，通过精确控制每个发射器的相位，让光波在特定方向上相干增强，其他方向上相互抵消。

    OPA 原理：

    激光输入
       │
       ▼
    ┌──┬──┬──┬──┬──┐  ← 光分束到 N 个波导
    │○│○│○│○│○│     （间距 d ≈ λ）
    └─┴─┴─┴─┴─┘
       │  │  │  │  │
       ▼  ▼  ▼  ▼  ▼
    相位控制器：φ₁, φ₂, φ₃, φ₄, φ₅

    远场干涉图案：

    强度
      │    ╭─╮
      │   ╱   ╲
      │  ╱     ╲
      │ ╱       ╲
      │╱    ↑    ╲
      └─────┼──────→ 角度
           主瓣方向
      （由相位梯度决定）

波束转向方程：

相邻发射器之间的相位差为 $\Delta\phi$ 时，主瓣方向为：

$$\theta = \arcsin\left(\frac{\lambda \cdot \Delta\phi}{2\pi d}\right)$$

通过改变 $\Delta\phi$，就可以电控激光束的指向——没有任何机械运动！

优点：
- 无任何活动部件（固态）
- 扫描速度极快（MHz级）
- 可任意编程扫描图案

缺点：
- 旁瓣干扰（能量泄漏到其他方向）
- 工艺难度大（需要精确控制每个通道的相位）
- 目前探测距离和分辨率还在提升中

代表厂商：Aurora、Analog Photonics、Voyant Photonics

类比：OPA像一支训练有素的合唱队。如果所有人都同时唱，声音均匀传播。但如果指挥让左边的人先开口、右边的人晚一点开口，声音就会”偏向”右边。OPA通过控制”谁先发光”来控制激光的方向。

2.5 Flash：一次照亮整个场景

如果扫描太慢，为什么不一次性照亮整个视野？这就是Flash LiDAR的思路。

    Flash LiDAR：

    宽束激光
       │
       ▼
    ════════════════════  ← 泛光照射整个场景
       │││││││││││││││
       ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼
    ┌──────────────────┐
    │                  │
    │    场景          │
    │                  │
    └──────────────────┘
       │││││││││││││││
       ▼▼▼▼▼▼▼▼▼▼▼▼▼▼▼
    ┌──────────────────┐
    │  SPAD阵列         │  ← 每个像素独立测距
    │  (如 256×256)     │
    └──────────────────┘

Flash LiDAR发射一束发散的激光（像相机的闪光灯），照亮整个场景。然后用一个二维探测器阵列（类似相机传感器，但每个像素都能独立测量光的飞行时间）同时接收所有反射光。

优点：
- 无扫描延迟（一帧搞定）
- 适合高速运动场景
- 无机械部件

缺点：
- 能量分散，探测距离短（通常<50m）
- 分辨率受探测器阵列限制
- 高功耗（需要很强的激光）

应用：
- iPhone Face ID（短距3D感知）
- 车内手势识别
- 机器人近距离避障

类比：Flash LiDAR像相机的闪光灯拍照。普通激光雷达像扫描仪——逐行扫描。Flash LiDAR直接拍一张”深度照片”。

第三部分：激光与探测器——LiDAR的”眼睛”

3.1 905nm vs 1550nm：不只是数字不同

激光雷达使用的激光波长主要有两种：905nm（近红外）和1550nm（短波红外）。

    光谱位置：

    400nm   700nm   905nm   1550nm
     │       │       │       │
    紫光    可见光   近红外  短波红外
     └───────┴───────┴───────┘
                        ↑
                   人眼不可见

这两种波长的核心区别在于人眼安全性。

人眼的光学结构：

    眼球剖面：

    角膜 ──→ 房水 ──→ 晶状体 ──→ 玻璃体 ──→ 视网膜
     │                                    │
     └──── 透明组织（可见光+近红外透过） ──┘

    对于 905nm：
    角膜和晶状体对它基本透明
    → 激光直接聚焦到视网膜上
    → 很小的功率就能灼伤视网膜
    → **安全功率阈值低**

    对于 1550nm：
    眼球内的水分子强烈吸收它
    → 激光在到达视网膜之前就被吸收了
    → 主要加热的是角膜和晶状体（能散热）
    → **安全功率阈值高 10-40 倍**

安全功率对比（IEC 60825-1 标准）：

波长 单脉冲安全能量 相对905nm
905nm ~50 nJ 1×
1550nm ~500-2000 nJ 10-40×

这意味着1550nm激光雷达可以使用更强功率的激光，从而获得更远的探测距离，而不会伤害人眼。

但1550nm也有缺点：
- 探测器效率低（需要用InGaAs材料，比硅贵）
- 激光器效率低、成本高
- 大气中水蒸气吸收更强（雨天性能下降）

类比：905nm像紫外线——它穿透玻璃（你的眼球），直接伤害内部。1550nm像微波炉辐射——它被水吸收，停留在表面。所以你用微波炉不会伤眼，但看紫外线灯很危险。

3.2 探测器：如何”看到”单个光子？

激光雷达的回波信号可能极其微弱——有时一个激光脉冲只返回几个光子！如何检测这么弱的信号？

PIN 光电二极管

最基础的探测器。光子入射产生电子-空穴对，形成光电流。

缺点：无内部增益，对微弱信号不敏感。

APD（Avalanche Photodiode，雪崩光电二极管）

    APD 原理：

    入射光子
       │
       ▼
    ┌─────────────┐
    │  吸收区     │  ← 光子产生电子-空穴对
    ├─────────────┤
    │  倍增区     │  ← 高电场（~10⁵ V/cm）
    │  (Avalanche)│     电子加速碰撞 → 产生更多电子
    ├─────────────┤     （雪崩效应）
    │  收集区     │
    └─────────────┘

    增益 M = 10 ~ 100
    1个光子 → 10-100个电子

APD在强电场下工作，每个被光子激发的电子在碰撞中释放更多电子，形成”电子雪崩”。增益可达10-100倍。

SPAD（Single-Photon Avalanche Diode，单光子雪崩二极管）

APD的升级版，工作在盖革模式（Geiger Mode）——电场极强，一个光子就能触发自持雪崩。

    SPAD 工作循环：

    偏置电压
       │    ╭──╮
       │   ╱    ╲     ← 高于击穿电压（盖革模式）
       │  ╱      ╲________
       │ ╱                 ╲___ ← 淬灭后降低
       └────────────────────────→ 时间
            ↑
         光子到达 → 雪崩 → 主动淬灭 → 恢复

    时间分辨率：<100 ps

SPAD的时间分辨率极高（<100皮秒），是ToF LiDAR的核心探测器。

SPAD阵列：把成千上万个SPAD像素排成阵列，每个像素独立计时。这样就能同时测量整个场景的深度。

类比：PIN二极管像人眼在白天看东西——足够亮就行。APD像夜视仪——能把微弱的光放大。SPAD像盖革计数器——它能”听到”单个光子的”咔嗒”声。

第四部分：点云——激光雷达的”视觉语言”

4.1 什么是点云？

激光雷达不输出照片，它输出点云（Point Cloud）——三维空间中的一组点，每个点有 $(x, y, z)$ 坐标和反射强度。

    相机看到的世界（2D）：        LiDAR看到的世界（3D点云）：

    ┌──────────────┐           •        •    •
    │  🚗  🚶  🌳  │          /|\      /|\   /|\
    │              │         • • •    • • •  • •
    │   道路       │        车轮廓    人轮廓   树轮廓
    └──────────────┘
    像素网格 (u, v)           三维点 (x, y, z, intensity)

一个典型的车载激光雷达，每秒输出数十万到数百万个点。

点云 vs 照片：

特性 相机（照片） LiDAR（点云）
维度 2D + 颜色 3D + 反射率
光照依赖 强（夜晚/逆光失效） 弱（主动发光）
纹理信息 丰富 无
距离信息 需估计 直接测量
计算量 大（深度学习） 中等（几何处理）

4.2 从原始点云到”理解”场景

原始点云是一堆无序的三维点，计算机需要把它变成”有意义”的信息。

处理流程：

    原始点云
       │
       ▼
    ┌─────────────┐
    │  地面分割   │  ← 区分地面点和非地面点
    │ (RANSAC)    │     （假设地面是平面）
    └──────┬──────┘
           │
           ▼
    ┌─────────────┐
    │  聚类       │  ← 把相邻点分成"团"
    │ (DBSCAN)    │     （每个团可能是一个物体）
    └──────┬──────┘
           │
           ▼
    ┌─────────────┐
    │  目标检测   │  ← 识别团是什么：车？人？树？
    │ (PointNet/  │
    │  PointPillar)│
    └──────┬──────┘
           │
           ▼
    ┌─────────────┐
    │  跟踪       │  ← 跨帧追踪同一个物体
    │ (卡尔曼滤波)│
    └──────┬──────┘
           │
           ▼
    带标签的3D物体列表
    [汽车1: (x,y,z,vx,vy), 汽车2: ..., 行人1: ...]

RANSAC（Random Sample Consensus）是地面分割的经典算法：

  1. 随机选3个点，拟合一个平面
  2. 计算有多少点”靠近”这个平面（距离<阈值）
  3. 重复多次，选”支持者”最多的平面作为地面

类比：点云处理像拼图。原始点云是散落在桌上的拼图碎片。地面分割是把”蓝色天空”的碎片挑出来。聚类是把相邻的碎片拼成小区域。目标检测是看出”这片碎片是马的身体”。跟踪是”这匹马在下一帧跑到了哪里”。

4.3 多传感器融合：LiDAR + 相机

激光雷达和相机是互补的：

  • LiDAR：精确的距离和形状，但没有颜色纹理
  • 相机：丰富的颜色和纹理，但不知道距离

把它们融合起来：

    LiDAR点云          相机图像           融合结果
       │                │                  │
       ▼                ▼                  ▼
    •••••••          ┌────────┐         ┌────────┐
    • 🚗 •           │  🚗🔴  │   →    │ 🚗 距离=15m
    •••••••          │  红色  │         │ 🚗 颜色=红色
                     └────────┘         └────────┘

    融合方法：
    1. 标定（Calibration）：找到LiDAR和相机的坐标变换关系
    2. 投影：把3D点投影到2D图像上
    3. 关联：给每个点赋予像素的颜色

融合的挑战：
- 时间同步（LiDAR和相机采集时刻不同）
- 空间标定（两者的坐标系对齐）
- 数据表示（如何把稀疏点云和稠密图像结合）

第五部分：产业格局——谁在造LiDAR？

5.1 技术路线之争

激光雷达产业正在经历一场”路线之争”——没有一种方案是完美的，每个厂商都在做不同的取舍。

    技术路线矩阵：

                 探测距离
         短 ←─────────────→ 长
         │
    低   │  Flash          MEMS
    成   │  (Face ID)      (Luminar)
    本   │
         │        OPA
         │     (Aurora)
         │
    高   │  机械旋转
    成   │  (Velodyne/禾赛)
         │

机械旋转路线：Velodyne（美国，鼻祖）、禾赛（中国，市占率第一）、速腾聚创（中国）、Ouster（美国，数字LiDAR）

MEMS路线：Luminar（美国，1550nm + MEMS，与沃尔沃/奔驰合作）、Innoviz（以色列，与宝马合作）

OPA路线：Aurora（美国，收购Blackmore的FMCW + OPA）、Voyant Photonics（美国）

Flash路线：Ibeo（德国，被采埃孚收购）、Sense Photonics（美国）

5.2 成本下降曲线

激光雷达的成本在过去10年下降了超过100倍：

年份 代表产品 价格 技术
2012 Velodyne HDL-64E $75,000 机械旋转
2017 Velodyne VLP-16 $7,999 机械旋转
2020 禾赛 Pandar40P ~$5,000 机械旋转
2022 禾赛 ET25 ~$500 半固态
2024 速腾 M1 Plus ~$300 MEMS
2025+ 多家目标 <$200 固态

成本下降的核心驱动力：
1. 芯片化：把激光器、探测器、驱动电路集成到芯片上
2. 规模效应：自动驾驶和ADAS（高级辅助驾驶）需求爆发
3. 中国供应链：激光器、探测器、光学元件成本大幅下降

类比：激光雷达的成本曲线像太阳能电池板——10年前贵得离谱，只适合航天和军事。现在便宜到可以装在你家门上（Face ID）和车顶上（辅助驾驶）。

5.3 特斯拉的”纯视觉”挑战

特斯拉是唯一坚持不装激光雷达的主流自动驾驶厂商。马斯克曾说”LiDAR是傻瓜的差事”。

特斯拉的逻辑：
- 人只有两只眼睛就能开车，为什么车需要激光雷达？
- 摄像头获取的信息密度远高于LiDAR（颜色、纹理、文字）
- 神经网络可以从2D图像中推断3D信息

反方观点：
- 人眼在夜晚、逆光、强光下也会失效
- 神经网络推断的深度精度不如LiDAR直接测量
- 安全关键系统需要冗余（摄像头+LiDAR互补）

现实：大多数自动驾驶公司（Waymo、百度、小马智行等）选择多传感器融合——既有摄像头，也有LiDAR，还有毫米波雷达。

第六部分：未来——LiDAR会走向何方？

6.1 芯片化：LiDAR-on-a-Chip

未来的激光雷达可能不再是”一个盒子”，而是一颗芯片。

    LiDAR芯片化演进：

    第一代：分立器件
    ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐
    │激光器│ │探测器│ │光学件│ │电路板│
    └─────┘ └─────┘ └─────┘ └─────┘

    第二代：模块化
    ┌─────────────────┐
    │   激光发射模块   │
    ├─────────────────┤
    │   探测接收模块   │
    └─────────────────┘

    第三代：芯片化
    ┌─────────────────┐
    │                 │
    │   LiDAR SoC     │  ← 激光器+探测器+驱动+DSP
    │   (5×5 mm²)     │     集成在一颗芯片上
    │                 │
    └─────────────────┘

芯片化的关键技术：
- 硅光子学（Silicon Photonics）：在硅芯片上集成光器件
- SPAD阵列CMOS工艺：用标准芯片工艺制造单光子探测器
- VCSEL（垂直腔面发射激光器）阵列：低成本、高可靠性

6.2 4D LiDAR：不只是三维

传统的LiDAR输出 $(x, y, z)$ 三维坐标。4D LiDAR增加了第四维——速度（通过多普勒效应或FMCW实现）。

    4D LiDAR输出：

    每个点：(x, y, z, v)

    场景：              带速度的点云：
    🚗 →               🚗 [x=10, y=0, z=0, v=+20m/s]
    🚶                  🚶 [x=5, y=2, z=0, v=+1m/s]
    🌳                  🌳 [x=20, y=5, z=0, v=0m/s]

知道每个点的速度，可以：
- 更快识别运动物体
- 预测轨迹（碰撞预警）
- 过滤静止背景（减少计算量）

6.3 从自动驾驶到万物互联

LiDAR的应用正在远远超出自动驾驶：

领域 应用 为什么需要LiDAR
消费电子 iPhone Face ID、扫地机器人 近距离3D感知
测绘 地形扫描、建筑建模 高精度三维重建
农业 作物高度监测、精准喷洒 大面积3D测量
气象 风速剖面、气溶胶监测 远程大气探测
航天 火星地形测绘、小行星着陆 无GPS环境下的导航
安防 周界监控、人流计数 全天候3D监控

写在最后

激光雷达的本质，是人类对”光”这一最古老物理现象的工程化利用。

从牛顿用棱镜分解阳光，到爱因斯坦解释光电效应，再到今天我们把激光脉冲的飞行时间测量到皮秒精度——这是数百年物理学积累的结晶。

当你看到一辆自动驾驶汽车头顶的激光雷达旋转时，请记住：那不是简单的”传感器”，而是一台精密的光学仪器，它在用光速的有限性丈量世界，用波的相干性控制方向，用量子力学的概率性探测光子。

一个数字：最先进的激光雷达可以在100米外，分辨出两个相距5厘米的物体——同时以每秒数百万次的频率重复这个过程。这相当于你站在足球场的一端，能看清另一端两根并排的筷子，而且每秒看一百万次。

这就是光的魔力。
