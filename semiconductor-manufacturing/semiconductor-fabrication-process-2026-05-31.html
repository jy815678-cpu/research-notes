半导体芯片制造工艺流程全景解读（2026-05-31）

目标读者：对半导体产业感兴趣的技术爱好者、投资者、以及希望建立完整认知框架的从业者。

目标：建立从”沙子”到”芯片”的完整制造图景，理解每一道工艺背后的物理原理、设备、以及为何摩尔定律能延续至今。

文档导读

你可能听说过”7纳米”、”EUV光刻机”、”台积电”这些词，但对芯片究竟是如何制造出来的，只有一个模糊的概念。这篇文档将带你走完芯片制造的完整旅程。

这不是一份工艺工程师的操作手册，而是一张认知地图。读完之后，你应该能够：

  • 自信地解释为什么光刻机是半导体产业的心脏
  • 理解”纳米制程”到底指的是什么
  • 明白为什么建造一座晶圆厂需要数百亿美元
  • 区分CVD、PVD、ALD这些听起来像外星语言的缩写
  • 知道你的手机芯片里到底发生了什么物理过程

第一部分：材料制备——从沙子到硅片

1.1 为什么是硅？

地球上最丰富的元素之一是硅（Silicon, Si），它占地壳质量的约28%。沙子的主要成分就是二氧化硅（$\text{SiO}_2$）。但芯片用的硅可不是直接从沙滩挖来的——它需要达到99.9999999%（九个9）的纯度。

为什么是硅，而不是锗或其他材料？

特性 硅 锗 砷化镓
bandgap（带隙） 1.12 eV 0.67 eV 1.42 eV
氧化物质量 极佳（$\text{SiO}_2$） 差（水溶性） 无天然氧化物
成本 极低 高 极高
高温稳定性 好 差 中等

硅的带隙适中，既不像锗那样漏电严重，也不像砷化镓那样难以大规模集成。最关键的是，硅能在表面生长出质量极高的二氧化硅层——这是制造晶体管栅极绝缘层的基石。

类比：硅就像面粉，便宜、易得、用途广。但要做蛋糕，你需要把面粉提纯到极高精度，否则蛋糕里会吃到沙子。

1.2 单晶硅生长：Czochralski 法

把高纯硅变成芯片的第一步，是拉出单晶硅锭（Monocrystalline Silicon Ingot）。

CZ 法（Czochralski Process）原理：

将高纯多晶硅放入石英坩埚，加热到约$1414^\circ\text{C}$（硅的熔点）。将一颗 tiny 的籽晶（Seed Crystal）接触熔融硅表面，然后以极慢的速度向上提拉并旋转。熔融硅在籽晶的引导下，按照相同的晶格方向凝固，形成一根巨大的单晶硅棒。

        籽晶 (Seed)
           │
           ▼
    ┌─────────────┐
    │  正在凝固的  │  ← 固液界面
    │  单晶硅棒    │
    ├─────────────┤  ← 熔融硅表面
    │             │
    │   熔融硅     │  ← 1420°C
    │  (Si melt)  │
    └─────────────┘
         石英坩埚

关键参数：
- 提拉速度：约$1\sim2\,\text{mm/min}$（慢得像蜗牛爬）
- 旋转速度：$10\sim20\,\text{rpm}$
- 一根标准晶棒：直径$300\,\text{mm}$（12英寸），长度可达$2\,\text{m}$，重约$100\,\text{kg}$

为什么必须是单晶？因为晶体中的缺陷（位错、晶界）会捕获电子，导致器件性能下降。多晶硅内部有大量的晶界，电子在其中就像在城市里遇到无数堵墙，根本无法高速移动。

类比：单晶硅像一条笔直的高速公路，电子可以全速奔驰。多晶硅像迷宫，电子到处碰壁。

1.3 切片与抛光：把晶棒变成”镜子”

晶棒拉好后，需要切成极薄的圆片：

  1. 切割：用金刚石线锯将晶棒切成约$775\,\mu\text{m}$厚的圆片
  2. 倒角：边缘磨成圆弧，防止后续搬运时崩边
  3. 研磨：用氧化铝等磨料去除切割损伤层
  4. 化学机械抛光（CMP）：这是关键一步，将表面抛光到原子级平整

CMP 的原理同时利用化学腐蚀和机械研磨：

$$\text{Si} + 2\text{OH}^- \rightarrow \text{SiO}_2 + 2\text{e}^- + \text{H}_2$$

生成的$\text{SiO}_2$被磨料机械去除，如此循环。

最终硅片的表面粗糙度需要达到亚纳米级别（约$0.2\,\text{nm}$ RMS），比镜子还光滑。为什么？因为后续光刻时，任何微小的表面起伏都会被投影放大。

类比：光刻机像一台投影仪，如果你把投影仪对准一张皱巴巴的纸，画面会扭曲。硅片必须像镜子一样平。

第二部分：前端工艺（FEOL）——建造晶体管

2.1 晶体管：芯片的基本单元

在深入工艺流程之前，你必须理解晶体管是什么。

MOSFET（金属-氧化物-半导体场效应晶体管）是现代芯片的核心。它本质上是一个电控开关：

         栅极 (Gate)
            │
    ════════╪════════  ← 多晶硅/金属栅
            │
      ┌─────┴─────┐
      │   SiO₂    │   ← 栅氧化层 (~1-2 nm)
      └─────┬─────┘
    ──┬─────┴─────┬──
      │   沟道    │     ← P型硅基底
      │  (Channel)│
    ──┴───────────┴──
      │           │
      ▼           ▼
    源极 (S)   漏极 (D)

当你给栅极施加电压时，会在栅氧化层下方的硅表面形成一个反型层（Inversion Layer）——这是一个薄薄的电子通道。电子可以从源极通过这个通道流向漏极，就像打开了一扇门。

关键物理量：
- 栅氧化层厚度 $t_{ox}$：约$1.2\,\text{nm}$（只有几个原子层厚！）
- 沟道长度 $L$：即”制程节点”（如3nm、5nm），决定了晶体管能开/关多快
- 阈值电压 $V_{th}$：栅极电压达到多少时”门”打开

类比：晶体管像水龙头。栅极是你拧开关的手，源极是自来水管，漏极是出水口。转动手柄（加电压），水就流出来。

2.2 氧化：生长栅氧化层

晶体管的核心是栅氧化层——它把栅极和沟道隔开，同时允许电场穿透。

热氧化（Thermal Oxidation）：

将硅片放入高温炉管（$900\sim1100^\circ\text{C}$），通入氧气或水蒸气：

  • 干氧氧化：$\text{Si} + \text{O}_2 \rightarrow \text{SiO}_2$（氧化层致密，质量高）
  • 湿氧氧化：$\text{Si} + 2\text{H}_2\text{O} \rightarrow \text{SiO}_2 + 2\text{H}_2$（速度快，但密度略低）

先进制程中，栅氧化层已改用高k介质（如HfO₂），因为纯SiO₂在1nm以下会产生大量隧穿漏电。

    氧化前          氧化后
    ┌─────┐        ┌─────┬─────┐
    │ Si  │   →    │ SiO₂│ Si  │
    └─────┘        └─────┴─────┘

2.3 光刻（Lithography）：半导体的心脏

如果让我选一项最重要的工艺，毫无疑问是光刻。它决定了你能把电路图案做多小。

光刻的本质是投影成像：

    光源 (Light Source)
        │
        ▼
    ┌─────────┐
    │ 掩模版   │  ← 铬版，有电路图案
    │ (Mask)  │
    └────┬────┘
         │
    投影透镜 (Projection Lens)
         │
         ▼
    ┌─────────┐
    │ 光刻胶   │  ← 涂在硅片上
    │ (Resist)│
    └────┬────┘
         │
    硅片 (Wafer)

光刻胶是一种光敏聚合物。曝光后，被光照到的部分（正胶）或未被照到的部分（负胶）会被显影液溶解，留下一个三维图案。

分辨率的物理极限：

根据瑞利判据，最小可分辨线宽为：

$$CD = k_1 \cdot \frac{\lambda}{NA}$$

其中：
- $\lambda$：光源波长
- $NA$：透镜数值孔径
- $k_1$：工艺因子（约$0.25$）

光刻技术 波长 $\lambda$ 典型制程 出现年份
g-line 436 nm $>500\,\text{nm}$ 1980s
i-line 365 nm $350\sim500\,\text{nm}$ 1990s
DUV (KrF) 248 nm $130\sim250\,\text{nm}$ 1997
DUV (ArF) 193 nm $65\sim130\,\text{nm}$ 2001
ArF+浸入式 193 nm $32\sim65\,text{nm}$ 2006
EUV 13.5 nm $<7\,\text{nm}$ 2019

EUV 光刻使用极紫外光（波长仅$13.5\,\text{nm}$），需要在真空中工作，因为空气会吸收这种短波长光。光源采用激光激发等离子体（LPP）：用高功率CO₂激光器轰击锡（Sn）液滴，产生13.5nm的辐射。

    CO₂ 激光器 ──→ 锡液滴发生器
         │           │
         └─────┬─────┘
               ▼
         等离子体发光
         (13.5 nm EUV)
               │
         多层反射镜收集
               │
         照明光学系统
               │
         掩模版 (Reflective)
               │
         投影光学系统
               │
         硅片 (真空环境)

一台EUV光刻机（ASML NXE:3600D）重达$180$吨，需要$10^6$个零件，售价超过$2$亿美元。它的精度相当于从地球射中月球上的一枚硬币。

类比：光刻机像一台超级精密的投影仪。普通投影仪投出的画面分辨率由灯泡波长决定——如果灯泡发红光，你不可能投影出比红光波长还细的线。EUV就像从红光升级到了X射线。

2.4 刻蚀（Etch）：把图案刻进硅里

光刻只是把图案转移到光刻胶上，下一步是把图案刻进硅或其他材料里。

湿法刻蚀（Wet Etching）：

用化学溶液腐蚀材料。例如，用氢氟酸（HF）腐蚀$\text{SiO}_2$：

$$\text{SiO}_2 + 6\text{HF} \rightarrow \text{H}_2\text{SiF}_6 + 2\text{H}_2\text{O}$$

湿法刻蚀是各向同性的——它向所有方向腐蚀，导致侧壁不垂直。在纳米尺度下这是致命的。

干法刻蚀（Dry Etching）—— 反应离子刻蚀（RIE）：

在真空腔中，用射频电场将气体电离成等离子体。等离子体中的离子在电场加速下轰击硅片表面，同时发生化学反应。

    射频电源 (RF Power)
         │
    ┌────┴────┐
    │  上电极  │  ← 通入刻蚀气体 (SF₆, CF₄, Cl₂等)
    ├─────────┤
    │  等离子体 │  ← 辉光放电区
    │  (Plasma)│
    ├─────────┤
    │  硅片    │  ← 放在下电极上，加偏压
    └─────────┘
    真空腔体

通过调节气体种类、气压、射频功率，可以实现：
- 各向异性刻蚀：离子垂直轰击，侧壁几乎不被刻蚀
- 高深宽比（High Aspect Ratio）：刻蚀深度/开口宽度 > 50:1

关键应用：FinFET中的鳍片（Fin）就是通过RIE刻蚀出来的。

    刻蚀前              刻蚀后
    ┌────┐             ┌──┐  ┌──┐
    │ Si │    →        │Si│  │Si│   ← Fin (鳍片)
    └────┘             └──┘  └──┘
    Si基底              Si基底

2.5 薄膜沉积：给芯片”穿衣服”

芯片制造需要沉积几十种不同的薄膜材料：绝缘层、导电层、阻挡层、钝化层…

CVD（化学气相沉积）

将气态前驱物输送到硅片表面，发生化学反应，生成固态薄膜：

$$\text{SiH}_4 + \text{O}_2 \xrightarrow{400^\circ\text{C}} \text{SiO}_2 + 2\text{H}_2$$

常见CVD类型：

类型 温度 应用
APCVD（常压） $300\sim500^\circ\text{C}$ 早期$\text{SiO}_2$
LPCVD（低压） $550\sim800^\circ\text{C}$ 多晶硅、氮化硅
PECVD（等离子体增强） $200\sim400^\circ\text{C}$ 低k介质、钝化层
HDPCVD（高密度等离子体） 室温$\sim400^\circ\text{C}$ 高深宽比间隙填充

PVD（物理气相沉积）

用物理方法将材料从靶材”搬运”到硅片上：

  • 蒸镀（Evaporation）：加热材料使其蒸发，在硅片上凝结
  • 溅射（Sputtering）：用氩离子轰击靶材，把原子”溅”出来

溅射是最常用的金属沉积方法（铝、铜、钨、钛等）。

    溅射示意图：

    氩离子 (Ar⁺)     靶材 (Target)
       ↓ ↓ ↓         ┌─────────┐
       → → →    →    │  Cu/W   │
                     └────┬────┘
                          │ 溅射原子
                          ▼
                     ┌─────────┐
                     │  硅片    │
                     │ (Wafer) │
                     └─────────┘

ALD（原子层沉积）

ALD是先进制程的核心技术。它通过交替通入两种前驱物，每次只沉积一个原子层：

  1. 通入第一种前驱物，化学吸附在表面，形成单分子层
  2. 抽走多余气体
  3. 通入第二种前驱物，与第一种反应，生成一个原子层的薄膜
  4. 重复步骤1-3
    时间轴 →

    前驱物A脉冲    |████    |████    |████
    吹扫 (Purge)   |    ░░░░|    ░░░░|    ░░░░
    前驱物B脉冲    |        |████    |    ████
    吹扫 (Purge)   |        |    ░░░░|        ░░░░

    一个ALD循环 ≈ 沉积 0.1 nm

ALD 的魔力：
- 完美的保形性（Conformality）—— 在垂直侧壁和深孔中的薄膜厚度与平面完全相同
- 原子级厚度控制
- 低温工艺（$50\sim300^\circ\text{C}$）

关键应用：高k栅介质（HfO₂）、金属栅（TiN/TaN）、DRAM电容介质。

类比：CVD像喷漆——快速但厚薄不均。ALD像一层一层贴纸——慢但每张贴纸厚度完全一致，连缝隙里都能贴满。

2.6 离子注入（Ion Implantation）：给硅”掺杂”

纯净的硅导电性很差。要制造晶体管，需要把硅的某些区域变成”电子富余”（N型）或”电子匮乏”（P型）。

掺杂原理：

  • N型掺杂：加入磷（P）或砷（As）——它们有5个价电子，多出的1个电子可以自由移动
  • P型掺杂：加入硼（B）——它只有3个价电子，会产生”空穴”（Hole），空穴也能导电

离子注入：

在真空腔中，将掺杂元素电离（如$\text{B}^+$、$\text{P}^+$、$\text{As}^+$），用高压电场（$10\sim500\,\text{keV}$）加速，轰击硅片表面。离子像微型子弹一样嵌入硅晶格中。

    离子源      质量分析器    加速管      硅片
      │           │          │         │
      ▼           ▼          ▼         ▼
    ┌───┐      ┌───┐      ┌───┐    ┌───┐
    │B⁺ │  →   │筛选│  →   │加速│ → │Si │
    └───┘      └───┘      └───┘    └───┘
                                    ↑
                               注入深度由
                               加速电压决定

注入深度 $R_p$ 与离子能量相关：

$$R_p \propto E^{0.5}$$

例如，$100\,\text{keV}$ 的硼离子注入深度约$0.3\,\mu\text{m}$。

退火（Annealing）：

离子注入会损坏硅晶格。注入后需要在$1000^\circ\text{C}$左右退火，让硅原子重新排列，同时激活掺杂原子。

先进制程中采用激光退火或快速热退火（RTA），时间仅几毫秒，防止杂质扩散。

类比：离子注入像把盐撒进面团里。退火像揉面——让盐均匀分布，同时让面团恢复弹性。

2.7 CMP（化学机械抛光）：平面化的魔法

芯片制造是三维堆叠的。每沉积一层，表面就会变得起伏不平。如果不处理，下一层的光刻会因为表面不平而失焦。

CMP 同时做两件事：
1. 化学：用浆料（Slurry）中的氧化剂腐蚀表面
2. 机械：用抛光垫（Pad）研磨表面

$$\text{去除速率} \propto \text{压力} \times \text{转速} \times \text{浆料活性}$$

CMP 的关键是终点检测——你怎么知道该停下来了？方法包括：
- 电机电流监测：磨到下层材料时摩擦力变化
- 光学干涉：监测反射光的颜色变化
- 涡流检测：检测下层金属的存在

    CMP 截面示意图：

    抛光头 (Platen) 旋转
         │
    ┌────┴────┐
    │ 抛光垫  │ ← 多孔聚氨酯
    ├─────────┤
    │ 浆料    │ ← SiO₂颗粒 + 化学试剂
    ├─────────┤
    │ 硅片    │ ← 被压在垫上旋转
    └─────────┘
         │
    硅片表面高低起伏
    → CMP 磨平 → 原子级平整

类比：CMP像给地板打蜡。你一边用化学清洁剂溶解污渍，一边用打磨机磨平。目标是让地板比镜子还平。

2.8 从平面晶体管到 FinFET

随着制程缩小到$22\,\text{nm}$以下，传统平面MOSFET遇到了短沟道效应：栅极控制不了漏电。

FinFET（鳍式场效应晶体管）解决了这个问题：

    平面晶体管              FinFET

    ┌─────┐              ┌─┐ ┌─┐
    │ Gate│              │ │ │ │  ← 栅极三面环绕Fin
    └──┬──┘              │ │ │ │
       │                 │ │ │ │
    ───┴───               └─┴─┘
    沟道 (Channel)         Fin (鳍片)
    ────────              ────────
    Si基底                  Si基底

在 FinFET 中，栅极三面环绕着垂直的硅”鳍片”（Fin），形成更好的静电控制。这大幅降低了关态漏电。

GAA（Gate-All-Around，环栅晶体管）是下一代架构：

    FinFET              GAA

    ┌─┐ ┌─┐           ╭───╮
    │ │ │ │           │ ╳ │   ← 栅极完全环绕纳米片
    │ │ │ │           ╰───╯
    └─┴─┘             ─────
                       纳米片

GAA 用水平的纳米片（Nanosheet）替代 Fin，栅极从四面完全包围沟道，静电控制能力更强。

第三部分：后端工艺（BEOL）—— 铺设信息高速公路

3.1 为什么要金属互连？

晶体管造好了，但它们彼此孤立。需要用金属线把它们连接起来，形成电路。

互连结构的演变：

    早期 (2层金属)          现代 (15+层金属)

    ┌──┐                    ┌──┐
    │M2│                    │M15│  ← 顶层：厚铜，供电
    ├─○┤                    ├─○┤
    │M1│                    │M14│
    ├─○┤                    ├─○┤
    │Si│                    │...│
    └──┘                    │M2 │
                            ├─○ ┤
                            │M1 │  ← 底层：细铜，信号
                            ├───┤
                            │Si │  ← 晶体管
                            └───┘

现代芯片有$10\sim20$层金属互连！每一层都需要光刻、刻蚀、沉积、CMP…

3.2 大马士革工艺（Damascene Process）

铜不能直接用干法刻蚀，所以采用大马士革镶嵌工艺：

  1. 沉积介电层（低k材料）
  2. 光刻 + 刻蚀：在介电层中刻出沟槽和通孔（Via）
  3. 沉积阻挡层（Ta/TaN，防止铜扩散到硅中）
  4. 电镀铜：用电化学沉积（ECD）填充沟槽
  5. CMP：磨掉多余的铜，只留下沟槽中的铜线
    大马士革工艺步骤：

    步骤1: 介电层        步骤2: 刻沟槽        步骤3: 沉积铜
    ┌─────────┐        ┌──┐   ┌──┐        ┌──┐   ┌──┐
    │  低k   │        │  │   │  │        │Cu│   │Cu│
    │  介质  │   →    │低k│   │低k│   →   ├──┤   ├──┤
    ├─────────┤        ├──┤   ├──┤        │低k│   │低k│
    │   Si    │        │Si│   │Si│        │Si│   │Si│
    └─────────┘        └──┘   └──┘        └──┘   └──┘

类比：大马士革工艺像制作镶嵌首饰。你先在木板上刻出凹槽，然后把金丝镶嵌进去，最后打磨平整。而不是先做好金丝再粘到木板上。

3.3 低k与超低k介质

随着金属线越来越密，线之间的寄生电容成为大问题：

$$C = \varepsilon_0 \varepsilon_r \frac{A}{d}$$

电容越大，RC延迟越长，信号传播越慢。

解决方案：降低介电常数 $\varepsilon_r$。

材料 $\varepsilon_r$ 应用
$\text{SiO}_2$ 3.9 传统介质
FSG（氟硅玻璃） 3.5 早期低k
SiCOH（有机硅玻璃） 2.5~2.7 超低k
多孔SiCOH 2.0~2.2 最先进低k
空气间隙 ~1.0 实验性

低k材料很脆弱，CMP时容易损坏，这是工艺中的重大挑战。

3.4 先进封装：从2D到3D

当晶体管缩小变得困难且昂贵时，行业转向封装创新来继续提升性能。

2.5D 封装（硅中介层）：

    ┌─────────┬─────────┐
    │  Chip 1 │  Chip 2 │  ← 多个裸片并排放置
    │ (Logic) │ (HBM)   │
    └───┬─────┴────┬────┘
        │          │
    ┌───┴──────────┴────┐
    │   硅中介层         │  ← 硅基板，上面有
    │  (Silicon          │     高密度互连
    │   Interposer)      │
    └─────────┬──────────┘
              │
         封装基板
              │
            PCB

3D 封装（芯片堆叠）：

    ┌─────────┐
    │  Chip 2 │  ← 存储芯片 (Memory)
    │ (HBM)   │
    ├───●─────┤  ← 微凸点 (Microbump)
    │  Chip 1 │  ← 逻辑芯片 (Logic)
    │ (SoC)   │
    └───┬─────┘
        │
    TSV (硅通孔)
        │
    封装基板

TSV（Through-Silicon Via）：在硅片上打垂直通孔，填充铜，实现上下芯片的电连接。

Chiplet（芯粒）架构：

把一个大芯片拆分成多个小芯片（Chiplet），每个用最适合的制程制造，然后用先进封装集成：

    单片SoC (Monolithic)          Chiplet架构

    ┌─────────────┐              ┌────┬────┬────┐
    │             │              │CPU │GPU │IO  │
    │   大芯片     │      →       │5nm │3nm │7nm │
    │  (7nm)      │              ├────┴────┴────┤
    │             │              │   互连桥      │
    │             │              │ (Interposer) │
    └─────────────┘              └──────────────┘
    良率低，成本高                良率高，成本低

类比：单片SoC像一块巨石雕像——一旦出错整块石头报废。Chiplet像乐高积木——你可以用不同的积木拼成任意形状，坏了一块换一块。

第四部分：良率——芯片制造的终极挑战

4.1 什么是良率？

良率（Yield） = 合格芯片数 / 总芯片数

一片$300\,\text{mm}$的晶圆上，如果制造$100$颗芯片，其中$90$颗合格，良率就是$90\%$。

听起来很高？但芯片制造的实际情况是：

良率公式（泊松模型简化）：

$$Y = e^{-A \cdot D}$$

其中：
- $A$ = 芯片面积
- $D$ = 缺陷密度（每平方厘米的缺陷数）

一颗先进的CPU面积约$800\,\text{mm}^2$，如果缺陷密度$D = 0.1\,\text{cm}^{-2}$：

$$Y = e^{-8\,\text{cm}^2 \times 0.1\,\text{cm}^{-2}} = e^{-0.8} \approx 45\%$$

近一半的芯片要报废！这就是为什么大芯片（如NVIDIA GPU、Apple M系列）如此昂贵。

4.2 缺陷的来源

缺陷类型 来源 影响
颗粒（Particle） 空气洁净度不足 短路/开路
光刻缺陷 掩模版缺陷、对焦不准 线宽异常
刻蚀残留 刻蚀不完全 短路
薄膜针孔 沉积质量差 漏电
CMP划痕 抛光垫颗粒 金属线断裂

晶圆厂的空气洁净度：

晶圆厂的核心区域达到Class 1标准——每立方英尺空气中大于$0.5\,\mu\text{m}$的颗粒不超过$1$个。作为对比：

  • 普通办公室：Class 1,000,000
  • 医院手术室：Class 10,000
  • 晶圆厂光刻区：Class 1

晶圆厂的工作人员穿兔子服（Bunny Suit）——全身包裹，连脸都遮起来，不是为了让工人看起来像宇航员，而是人本身就是最大的颗粒来源！一个人静止时每秒释放约$100,000$个颗粒。

类比：晶圆厂像一个巨大的无尘手术室。一个喷嚏就能毁掉价值数万美元的晶圆。所以你在晶圆厂里看不到任何人——他们都在兔子服里。

4.3 测试：怎么知道芯片是好的？

晶圆测试（Wafer Test / Probe Test）：

在切割芯片之前，用探针卡（Probe Card）接触晶圆上的测试点，检测每颗芯片的电气性能。

测试内容：
- 参数测试：阈值电压、漏电电流、电阻、电容
- 功能测试：逻辑功能是否正确
- 速度测试（Sort）：芯片能跑多快（分Bin）

封装后测试（Final Test）：

芯片封装后再次测试，确认封装过程没有损坏芯片。

老化测试（Burn-in）：

在高温（$125^\circ\text{C}$）高压下运行芯片数小时到数天，加速老化，剔除早期失效的”弱鸡”芯片。

写在最后

从沙子到芯片，总共需要超过1000道工序，在极净无尘的环境中，用价值数百亿美元的设备，耗时2到3个月。一颗现代CPU里有数百亿个晶体管，每个晶体管只有几纳米大小——这比人类头发直径的万分之一还要小。

这就是人类制造的最复杂的东西。没有之一。

一个数字：制造一片$300\,\text{mm}$晶圆需要约$10^{25}$个原子被精确排列。这相当于把地球上每一粒沙子都精确放到指定位置——而且不允许出错。
